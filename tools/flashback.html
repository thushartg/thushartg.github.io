Flashback

About

Native macOS 14+ menu bar utility that keeps the last 1–30 seconds of your screen as hardware-encoded H.264 video in RAM so you can scrub back, copy vanished text via Live Text, or drag out an MP4 clip.

Challenge

Full-day screen recorders burn SSD write cycles and index sensitive windows onto disk when all you needed was an error toast or SQL result that disappeared five seconds ago.

Memory Hygiene

Zero third-party dependencies and zero continuous disk writes. Compressed H.264 segments stay strictly in volatile RAM and purge automatically on pause, manual clear, or display sleep.
