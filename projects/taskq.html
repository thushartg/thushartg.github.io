TaskQ

About

Containerized asynchronous prompt router built with FastAPI, Redis, PostgreSQL, and React that classifies incoming tasks and runs LLM completions off the HTTP loop.

Challenge

Calling upstream inference APIs synchronously inside web handlers blocks worker threads whenever completion latency spikes. Separating admission from execution keeps API latency flat.

Persistence

Prompts, intent labels, status transitions, and worker outputs are keyed to client UUIDs in PostgreSQL via SQLAlchemy so sessions survive reloads cleanly.
