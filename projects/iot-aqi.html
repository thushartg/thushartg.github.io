AQI Telemetry

About

Hardware-to-mobile telemetry pipeline streaming particulate and gas sensor readings to ThingSpeak Cloud and surfacing live AQI trends and threshold alerts in a native Swift iOS client.

Calibration

Raw sensor voltages drift with ambient temperature and humidity unless calibrated before cloud ingestion. Microcontroller ADC normalization stabilized channels prior to streaming.

Mobile Client

A native Swift iOS dashboard polls ThingSpeak time-series channels and triggers local threshold alerts when particulate concentrations cross safe indoor bands.
